📚 Bibliothèque Management System
📖 Description

Ce projet est une application web de gestion de bibliothèque développée dans le cadre d'un projet académique. Elle permet de faciliter la gestion des livres, des emprunts et des utilisateurs à travers une interface intuitive et conviviale.

L'objectif principal est d'automatiser les opérations courantes d'une bibliothèque tout en appliquant les concepts du développement web et de la programmation orientée objet.
