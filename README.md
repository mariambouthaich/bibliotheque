📚 Bibliothèque Management System


📖 Description

Ce projet est une application web de gestion de bibliothèque développée dans le cadre d'un projet académique. Elle permet de faciliter la gestion des livres, des emprunts et des utilisateurs à travers une interface intuitive et conviviale.

L'objectif principal est d'automatiser les opérations courantes d'une bibliothèque tout en appliquant les concepts du développement web et de la programmation orientée objet.

🎯 Objectifs du projet
Gérer efficacement le catalogue des livres.
Faciliter le suivi des emprunts et des retours.
Permettre l'administration des utilisateurs.
Offrir une interface simple pour les bibliothécaires et les lecteurs.

Description des dossiers

assets/ : fichiers CSS, JavaScript et ressources statiques.
config/ : configuration de la base de données et de l'application.
controllers/ : logique métier et traitement des requêtes.
database/ : scripts SQL et gestion de la base de données.
models/ : manipulation des données.
sessions/ : gestion des sessions utilisateurs.
views/ : interfaces utilisateur.

📌 Contexte académique
